# Contributing to RedCat

Thank you for wanting to contribute to RedCat. Contributions are open to everyone — but every change is merged **only after the maintainer reviews and approves it**. There is no auto-merge, and no code is merged without approval.

## How to contribute

1. **Fork the repository.** Click **Fork** on the RedCat repo page to create your own copy under your GitHub account.
2. **Create a branch.** In your fork, create a branch for your change. Use a clear name, for example `fix/login-error` or `feature/dark-mode`.
3. **Make your change.** Keep it focused on one thing. Write in English — all code, comments, UI text, and documentation in this project are in English.
4. **Test what you changed.** Run the app and verify your change works. Do not submit a change you have not run. If your change adds a feature, describe how you tested it in the pull request.
5. **Submit a pull request.** Open a pull request from your branch to the `main` branch of `manamaliahmad/redcat`. Describe what you changed and why, and how you tested it.

## How pull requests are reviewed

- Every pull request is reviewed by the maintainer (**manamaliahmad**).
- A pull request is merged **only after the maintainer approves it**. One approving review from the maintainer is required before any merge.
- Direct pushes to `main` are not allowed. All changes go through a pull request.
- If a change needs work, the maintainer will ask for it in the pull request. Please respond there — do not open a second pull request for the same change.
- Be patient. Reviews take as long as they take; the goal is a correct change, not a fast one.

## Ground rules

- **No fake data.** Never invent a statistic, a link, a screenshot, or a test result. If something is not verified, say so or leave it out.
- **No secrets.** Never commit an API key, a token, a password, or any credential. Keys live in the user's own Settings, never in the code.
- **No other user's data.** Never commit chats, memory files, run logs, or any personal data. A fresh install must start from zero.
- **English only.** All user-facing text, comments, and documentation are in English.
- **Respect the license.** RedCat is MIT licensed. By submitting a pull request, you agree that your contribution will be released under the same MIT License.

## Getting help

If you are unsure how to do something, open an issue describing what you want to do before writing the code. You can also ask in the community Discord server: https://discord.gg/4r8NwtnFB
