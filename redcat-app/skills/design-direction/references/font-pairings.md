# Font pairings (display + body)

Pick one pair per page. Display is for headings and hero only; body is for
everything readable. Never use Inter, Space Grotesk, Arial, or Roboto as the
default pick — the pairs below are the defaults instead.

## 1. Fraunces + Manrope
- Subjects: cafe, bakery, salon, boutique, premium local business
- Note: soft serif display with a clean grotesque body; warm and premium.

## 2. Playfair Display + Work Sans
- Subjects: fashion, photography, hotel, law firm, editorial portfolio
- Note: high-contrast serif display; Work Sans keeps long text calm.

## 3. DM Serif Display + DM Sans
- Subjects: restaurant, clinic, real estate, school
- Note: friendly serif display; DM Sans is readable at small sizes.

## 4. Libre Caslon + Source Sans 3
- Subjects: dental clinic, medical clinic, charity, consultancy
- Note: trustworthy bookish serif; Source Sans 3 is quiet and long-form safe.

## 5. Bricolage Grotesque + Instrument Sans
- Subjects: SaaS, tech startup, app page, designer portfolio
- Note: characterful display grotesque; Instrument Sans stays neutral in body.

## 6. Instrument Serif + Manrope
- Subjects: wedding, events, mehndi artist, luxury services
- Note: Instrument Serif is elegant at large sizes; Manrope carries details.

## 7. Newsreader + IBM Plex Sans
- Subjects: law firm, school, NGO, editorial content
- Note: Newsreader reads like print; IBM Plex Sans is precise in body.

## 8. Sora + Lora
- Subjects: gym, auto workshop, mobile shop, electronics
- Note: Sora is strong and modern for headings; Lora softens long text.

## 9. Merriweather + Outfit
- Subjects: real estate, furniture, interior, travel
- Note: sturdy serif display; Outfit is geometric and clean in body.

## 10. Space Mono + Work Sans
- Subjects: tech startup, developer portfolio, electronics
- Note: mono display only for labels and numbers, never for paragraphs.

## Rules
- One display font per page. A second display font is a second voice.
- Display sizes: hero 44-72px desktop, 34-40px mobile. Body: 16-18px, never
  below 15px for paragraphs.
- Headings use text-wrap: balance. Body text uses a comfortable measure,
  roughly 60-70 characters per line on desktop.
- If a pairing feels wrong for the subject, change the pair, not the palette.
