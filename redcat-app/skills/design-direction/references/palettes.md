# Palettes (20, mapped by subject)

Each palette has four tokens that map straight to `:root`:
`--bg, --fg, --accent, --muted`. Neutrals always carry a hue tilt, never pure
grey. Pick the closest subject; if none fits, build one in the same shape.

## 1. Dental clinic — clean mint
- Subject: dental clinic, dentist portfolio
- --bg: #F4FBF8, --fg: #122E28, --accent: #0E9B7E, --muted: #5D7A72
- Note: clinical but warm; mint reads clean, not cold.
